🔧 Install Stihl Parts Collector

One-time setup. Takes about 60 seconds.

  1. Open Chrome and go to chrome://extensions
  2. Turn on Developer mode (toggle in the top-right corner)
  3. Click Load unpacked and select the stihl_extension folder (the folder containing this file)
  4. The 🔧 icon will appear in your Chrome toolbar — pin it for easy access

How to use:

  1. Log in to the Stihl dealer portal at ssc.stihl.com
  2. Open any model's IPL page
  3. Click the 🔧 icon — the model is detected automatically
  4. Hit Add this model (optionally edit the name first)
  5. Repeat for each model you want
  6. Click Build & Download CSV — file downloads instantly
Token note: The extension grabs your login token automatically from the Stihl portal — you never need to copy it manually. If you see a "token expired" message, just open the Stihl portal tab and click the extension icon again.
